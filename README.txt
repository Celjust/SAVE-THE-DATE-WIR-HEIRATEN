CÉLINE & JUSTIN · FERTIGE HOCHZEITSWEBSEITE

Dieses Paket enthält eine einzige, vollständige Webseite: index.html.
Alle vier Originalskizzen, sämtliche Schriftdateien, die Gestaltung und
das JavaScript sind direkt in dieser Datei eingebettet.
Die Bilder werden sofort geladen; ein Bilderordner ist nicht erforderlich.

SO HOCHLADEN

1. ZIP entpacken.
2. Die Datei index.html in denselben Veröffentlichungsordner des
   GitHub-Repositories hochladen, in dem bisher die Startseite liegt.
3. Die bisherige index.html damit ersetzen und die Änderung speichern.

Keine style.css, kein script.js, kein fonts- oder skizzen-Ordner nötig.
Vorhandene andere Dateien im Repository können bleiben.
Die direkt angebotene index.html und die index.html in diesem ZIP sind identisch.

VORSCHAU

Die heruntergeladene index.html direkt in einem Webbrowser öffnen.
Die vier Bilder und Schriften benötigen keine Internetverbindung.
Der Kartenlink öffnet Google Maps und benötigt eine Internetverbindung.
